# Prospective confirmatory study: proposed design, not yet registered or executed

1. Formulate a precise behavioral/mechanistic hypothesis independent of any claim about phenomenal consciousness.
2. Use at least two independently implemented environments: one 1-D motor remapping setting and one 2-D multi-goal environment with new obstacle types.
3. Include randomly initialized networks with genotype mutations affecting topology; predefine computation and energy costs. Explicitly inventory all hand-designed inductive biases.
4. Predefine primary controls: evolution with/without recurrence, action–outcome history scrambles, random-fitness selection, de-novo mutation without inheritance, fixed vs changing environment, and action-blind-but-history-capable baselines.
5. Separate development seeds from untouched evaluation seeds; choose hyperparameters using development seeds only.
6. Define statistical unit (independently initialized evolving population), sample size justified by pilot variance, the exact primary outcome, intervention and test conditions, exclusion rules, multiple-testing adjustments and bootstrap procedures before running.
7. Deposit an independently timestamped preregistration and source release before the confirmatory run; preserve failure runs, computational environment, random seeds, and immutable checksums.
8. If the confirmatory effect survives, claim evolved sensorimotor computation—**not** a solved theory of conscious subjective experience.

This is a protocol template and has not been externally preregistered.
