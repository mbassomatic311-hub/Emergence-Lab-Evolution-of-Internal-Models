# Emergence Lab — Experiment 08E: Unlabeled, online action–outcome learning

**Status:** Exploratory DEVELOPMENT study (post-hoc design in the ongoing Experiment 08 series). Not publicly preregistered, not independently peer reviewed, and **not a measurement of consciousness**. No confirmatory seed pool has been generated or examined.

## Motivation and what is different from 08D

In Experiment 08D, a hand-structured observer was fitted to the simulator's TRUE hidden motor rotations during offline training. That supervised procedure cannot show learning by an agent that receives only ordinary sensory experience. Here a new agent starts with all motor-effect estimates set to zero. During a simulated lifetime it compares a *previously issued motor command* with a later change in food-relative bearing, and updates an action-specific two-dimensional displacement prediction. **No hidden rotation labels are read by the learner or controller.**

This does **not** make the architecture spontaneous: we coded the four action channels, input bearing representation, valid-transition criteria, prediction-error formula, exponential update, and action-selection rule. The experiment tests a narrower hypothesis: can a specified online prediction mechanism learn useful action-conditioned information without receiving ground-truth hidden states?

## Environment, seeds, and experimental units

Reuse the original 2D Experiment 08 world (`world2d.py`): 13×13 bounded map, blockers, target-relative noisy vector observations, stochastic motor slips and environmental gusts. An unobserved actuator mapping is randomly selected at the start of each episode. In the shift setting, the mapping changes by 180° at step 24 and food-target vector observations disappear with 12% probability. The agent has 48 decisions per episode.

Six **new development-only seed namespaces** 23M–28M; 24 seeds per namespace = **144 worlds** for prequential prediction and another disjoint 144 starting seeds for closed-loop food/survival scoring. No confirmatory outcome data. The *world* is the analysis unit: individual steps from one world are serially dependent. All prediction-model arms get the **same open-loop world trajectories**, generated by identical external random motor commands. Closed-loop policy conditions share starting seeds but have necessarily different downstream trajectories.

## Controllers and ablations

- `action_model`: starts with four zero displacement vectors; each valid action→observation transition updates ONLY its corresponding motor channel (EMA coefficient 0.60). Uses estimated vectors to choose goal-directed commands, with prescribed exploration.
- `shuffled_action`: same rules but assigns each learning update to an independent random action key. This destroys the correspondence between the command that caused movement and the learnt table entry; controller retains the same four channels.
- `action_blind`: uses a single unconditioned moving-average displacement estimate for all actions; cannot select actions by motor-specific effects.
- `reset_memory`: discards model history before each decision; no cumulative sensory–motor model.
- `greedy`: uncompensated food-directed command, without learning motor mappings.
- `comparator`: previously coded hand-engineered four-rotation feedback estimator.
- `bayesian`: previously coded four-hidden-state Bayesian filter with hand-engineered geometric likelihood.

The four learners were evaluated for prequential **motor-effect prediction squared error**: each forecast was issued *before* the next observation, and the measured displacement was used only for later updates. Exclude transitions following food respawn, visible collision or sensor dropout. This is an intentionally restricted diagnostic of observable outcomes, not a state-reconstruction test. No privileged rotation labels used in learning, controller evaluation or prediction-error scoring.

## Development results

### Open-loop prequential prediction, 144 matched simulated worlds per method

| Method | Before reversal MSE ↓ | After reversal MSE ↓ |
|---|---:|---:|
| Unlabeled action-specific learner | **0.6741** | 1.3988 |
| Action-history key shuffled | 1.4656 | 1.5857 |
| Action-blind single outcome model | 1.6440 | 1.6996 |
| Memory reset every step | 1.0409 | **1.0640** |

**Caution:** the action-specific learner does worse than no-memory after reversal: its stored action mappings become wrong when dynamics abruptly change, and this fixed-lifetime/simple EMA cannot fully catch up. Action-conditioned memory helps before change but is not universally beneficial. Full time-binned prediction errors and change-point recovery should be studied prospectively.

Descriptive post-hoc **paired world-bootstrap** intervals for mean squared error of action learner *minus* comparator (negative favors action learner):

| Comparison | Pre-reversal difference (95% bootstrap interval) | Post-reversal difference (95% bootstrap interval) |
|---|---|---|
| vs shuffled action | −0.7915 [−0.8545, −0.7296] | −0.1869 [−0.2684, −0.1068] |
| vs action-blind | −0.9699 [−1.0191, −0.9201] | −0.3008 [−0.3542, −0.2478] |
| vs memory reset | −0.3668 [−0.3982, −0.3349] | **+0.3348** [+0.2899, +0.3804] |

These are exploratory estimates of Monte Carlo variation under one designed model, not confirmatory significance tests, biological uncertainty estimates, or novel neuroscience results. Controls do not necessarily have equal computation/complexity, and the environment and algorithm are investigator-built.

### Closed-loop navigation, 144 different development episodes per method and setting

Mean food rewards per 48-step simulated episode:

| Controller | Stable | Shift + 12% dropout |
|---|---:|---:|
| Unlabeled action-specific learner | 2.139 | 0.792 |
| Action-history shuffled | 0.083 | 0.056 |
| Action-blind estimate | 0.146 | 0.167 |
| Memory reset | 0.146 | 0.167 |
| Greedy/no motor correction | 0.833 | 0.417 |
| Hand-coded 4-rotation comparator | 3.764 | 2.653 |
| Hand-coded Bayesian filter | **3.514** | **2.958** |

The action-specific learner beats greedy by **+0.375** foods after shift (exploratory paired seed-bootstrap 95% interval **[+0.167, +0.576]**), but loses against the Bayesian model by **−2.167** foods (**[−2.486, −1.854]**, precise interval in `exploratory_intervals.json`). This is a functional advantage in this simulation, **not** general self-model emergence or superiority to established algorithms.

### Limitations, hypotheses, novelty

1. The action-to-sensory change representation and delta learning rule are **explicitly engineered**, not evolved. No neural architecture emerges from zero connections, and the method is not a consciousness detector.
2. Food-relative bearing is specially informative because changes directly encode the agent's position change while a target remains fixed. This feature may not exist in other worlds; cross-domain generalization remains untested.
3. The update rule uses the simulator-provided respawn/collision/visibility flags to filter unreliable transitions. These are allowed observations but meaningful inductive bias.
4. Abrupt motor reversal creates **maladaptive memory**, shown by the post-shift no-memory baseline being more predictive. A future test should preregister adaptation metrics after a change and compare reset/change-point detection.
5. Action-blind and reset-memory closed-loop policies are both effectively random in this implementation. They are distinct **prediction** ablations but are **not** independent navigation policies.
6. We ran multiple iterative developmental analyses in this series. There has been no independently registered prospective hypothesis; effect sizes and bootstrap intervals must be labeled exploratory.
7. Artificial predictions are not evidence of first-person subjective experience. Forward models, online adaptive control, efference copy and sensorimotor learning are long-established ideas; **no novelty claim** is made.
8. The world is a single deliberately designed simulator family, not biological evolution or independent external replication.

## Reproduction

Requires NumPy. Tested locally with Python 3.13.5, NumPy 2.3.5, `OPENBLAS_NUM_THREADS=1`.

```bash
cd experiments/exp08
OPENBLAS_NUM_THREADS=1 python -m unittest -q test_exp08.py test_audit_fitness_noise.py test_audit_world_controls.py test_audit08c_learning.py test_audit08d_learning.py test_audit08e_selfsupervised.py
OPENBLAS_NUM_THREADS=1 python audit08e_selfsupervised.py --probes 24 --navigation 24 --out /tmp/exp08e-repeat
OPENBLAS_NUM_THREADS=1 python audit08e_analyze.py --data-dir /tmp/exp08e-repeat
```

Compare `summary.json`, both `.csv` tables and `exploratory_intervals.json` with files committed under `development_selfsupervised08e/`. All seeds appear explicitly in output rows. For safety, **never replace older experiment data**; always keep a separate analysis folder and label any subsequent development revisions.
