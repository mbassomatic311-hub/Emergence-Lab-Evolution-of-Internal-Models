# Experiment 08I — nonlinear distance-feedback prediction (development only)

Research question: does label-free action-conditioned prediction transfer to unexpected physical changes using **nonlinear landmark distances** rather than direct linear displacement readings? The main outcome is prequential squared prediction error, not cause labeling, consciousness, or selfhood.

Seven fixed algorithms share the same externally generated action–sensory trajectories. The small 48-seed experiment is exploratory, including some seeds inspected during pilots. Nonparametric nearest-neighbor memory wins in the low-noise setting; engineered nonlinear regression wins under higher noise. Restricted-action histories impair prediction of untried actions.

Start with [DEVELOPMENT_AUDIT_08I.md](DEVELOPMENT_AUDIT_08I.md). Run `python -m unittest -v test_experiment08i.py` and inspect the reproducibility instructions in that report.

**Cautions:** This is a researcher-authored second task, not an independently authored/validated environment; no evolutionary acquisition, autonomous hypothesis invention, registered confirmatory seeds, peer review or consciousness measure. The predictor features, forgetting rates and action schedules are given by the researcher.
