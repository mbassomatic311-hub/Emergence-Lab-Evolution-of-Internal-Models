# Emergence Lab — Evolution of Internal Models

**Exploratory computational research** on the evolution of adaptive sensing, memory, prediction, and action–outcome models.

> These simulations do **not** establish machine consciousness, the evolution of subjective experience, or a novel biological discovery. This repository is a research-in-progress. Experiments 01–07 were not publicly preregistered and have not been independently peer reviewed.

## Import the complete research archive

The complete, integrity-checked research package is prepared but **has not yet been imported**. To populate this repository, open **Add file → Upload files** at the top of the GitHub repository, add the prepared `Emergence_Lab_GitHub_Starter.zip` archive at the repository root, and commit it to `main`.

The GitHub Actions workflow `.github/workflows/import-research-package.yml` should automatically:

1. Verify that the ZIP contains the expected research materials.
2. Check its integrity against the included SHA-256 manifest.
3. Extract the 186 research files into their intended folders.
4. Remove the ZIP and commit the extracted files to `main`.

Watch progress under the repository's **Actions** tab. If the action cannot push, visit **Settings → Actions → General → Workflow permissions** and permit read-and-write permissions, then rerun the workflow. Do not claim a full import until `experiments/`, `docs/`, and `SHA256SUMS.txt` appear on `main`.
